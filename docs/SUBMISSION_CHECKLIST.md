## Public GitHub upload (once reviewed)

1. Create a new public repository named `sideline-wr-capstone` on GitHub.
2. Upload the contents of the extracted `wr_capstone` folder. Include source,
   templates, static files, requirements, README, data, model, tests, and docs.
   Exclude .venv and __pycache__.
3. Verify the public URL works when signed out. Do not invent a repository URL.
4. Download the ZIP from GitHub on another computer and follow README.
5. Record OS, Python version, commands, and observed success/failure.

## User acceptance tasks

Ask 3 classmates or fantasy users to select two receivers, compare opportunity
and matchup stats, find the recommendation, recognize a close comparison, and
identify missing route/injury information. Record completion, misunderstandings,
time taken, and feedback. This is a plan, not testing already performed.

## Recording outline

Explain the problem and project contribution, demonstrate receiver selection,
show projections and evidence, discuss evaluation findings honestly, explain
the Python/SQL methodology, and reflect on limitations and future improvements.
Keep your face on screen. Confirm the required duration with the assignment.
